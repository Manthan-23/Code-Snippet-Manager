Code snippet Manager(Snipp-It) is a platfrom designed for programmers and developers to save there valuable piece of codes which they use on daily basis or may need it in future. Users can also connect to there GitHub account so that they get 
direct access to there GitHub repos and can save the piece of codes directly from there.

##Tech Stack used:
1. SpringBoot
2. HTML & CSS
3. MySQL
4. GitHub OAuth and Repository Integration
   

**To check the Github functionality please login first and go to the account section first for GitHub connection(As there is a small routing issue).**


Live Project Deployed Link: https://snipp-it.onrender.com
